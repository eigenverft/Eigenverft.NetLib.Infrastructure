0.1.0 (2026-09-25)

- Created the SerilogRelay library in Eigenverft.NetLib.Infrastructure and migrated the revival context from Eigenverft.NetLib.SerilogCentralLoggingSink.
- Functionally migrated the archived AxonInsight SQLiteSinkHttp sender: durable local SQLite spool, restart recovery, background HTTP batching, sent-state updates, retention, retry/backoff, Retry-After handling, and shutdown flush.
- Preserved the historical wire behavior while renaming the pre-release public API to `SerilogRelaySink` and `.WriteTo.SerilogRelay(...)` so it matches the package purpose.
- Updated Microsoft.Data.Sqlite from the archived 9.0.6 reference to 10.0.12 to satisfy the repository vulnerability gate.
- Refreshed direct dependencies to current stable releases, including Serilog 4.4.0, Microsoft.NET.Test.Sdk 18.10.1, MSTest 4.4.1, and coverlet.msbuild 10.0.1.
- Corrected composite retention cleanup to use a valid single SQLite relative-time modifier while retaining SQLite as the source of the current clock.
- Stopped taking ownership of Serilog's process-global SelfLog configuration and restored HTTP status/transport diagnostics through caller-configured SelfLog.
- Replaced hand-written property JSON escaping with source-generated System.Text.Json while preserving the historical stringified Serilog property-value contract.
- Added 15 regression tests covering persistence, restart recovery, delivery, SQLite busy handling, HTTP failure/throttling paths, shutdown behavior, and sender lifecycle; the authored net10 library code is at 100% line, branch, and method coverage.
