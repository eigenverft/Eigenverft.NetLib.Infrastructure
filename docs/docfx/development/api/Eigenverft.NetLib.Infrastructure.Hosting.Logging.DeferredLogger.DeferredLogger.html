Class DeferredLogger

Default implementation of IDeferredLogger that wraps an ILogger.

Namespace: Eigenverft.NetLib.Infrastructure.Hosting.Logging.DeferredLogger
Assembly: Eigenverft.NetLib.Infrastructure.dll
Syntax
public sealed class DeferredLogger : IDeferredLogger
Remarks

This implementation can create an ILogger via ILoggerFactory using either a fixed category name or an explicitly provided category name. Consumers may also wrap an existing ILogger instance.
