AddWritebackJsonStore<T>(IServiceCollection, string, bool, JsonSerializerOptions?)

Creates a WritebackJsonStore<T> for the specified JSON document and registers it as a singleton.

Declaration
public static IServiceCollection AddWritebackJsonStore<T>(this IServiceCollection services, string filePath, bool watchForExternalChanges = true, JsonSerializerOptions? serializerOptions = null) where T : class, new()
Parameters
Type Name Description
IServiceCollection services

The service collection to add the singleton registration to.
string filePath

Absolute or relative path of the backing JSON document.
bool watchForExternalChanges

When true, the store watches the backing file and reloads successful external changes into Current.
JsonSerializerOptions serializerOptions

Optional serializer options used for load, clone, and save operations.
Returns
Type Description
IServiceCollection

The same service collection so additional registrations can be chained.
Type Parameters
Name Description
T

The typed settings or document model managed by the store.
Remarks

The registered store exposes two deliberately separate mutable branches. Current is the file-backed state changed through MutateCurrentAndSave(Action<T>, bool) or external reloads. RuntimeWorkingCopy is a detached in-memory branch for runtime-only work that must not implicitly change the JSON document.

A persisted mutation can be observed independently by normal JSON configuration or SwitchableJson when that configuration source has reload-on-change enabled. The writeback store itself does not trigger configuration reloads or participate in configuration-source switching.

Examples
services.AddWritebackJsonStore<RuntimeSettings>("Settings/runtime-settings.json");
Exceptions
Type Condition
ArgumentNullException

Thrown when services or filePath is null.
