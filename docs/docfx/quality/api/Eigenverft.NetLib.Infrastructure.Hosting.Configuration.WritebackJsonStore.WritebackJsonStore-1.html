Class WritebackJsonStore<T>

Manages a typed JSON document with two deliberately separate mutable branches: the file-backed Current state and a non-persisted RuntimeWorkingCopy.

Type Parameters
Name Description
T

Document type. Must be a reference type with a public parameterless constructor.
Remarks

The store captures InitialSnapshot once when it is created. Current represents the document that was most recently loaded from or written to the backing file. RuntimeWorkingCopy is an intentionally detached in-memory branch for runtime-only work that must not implicitly modify the file.

Use MutateCurrentAndSave(Action<T>, bool) when a change is intended to become persisted configuration. Use MutateRuntimeWorkingCopy(Action<T>, bool) when code needs to work with the same typed model without persisting those changes. Changes to Current do not automatically overwrite RuntimeWorkingCopy; call RestoreRuntimeWorkingCopyFromCurrent(bool) explicitly when the runtime branch should discard its own changes and start again from the current file-backed state.

The store is not an IConfiguration provider and does not trigger configuration reloads itself. It can be used beside normal JSON configuration or SwitchableJson with reload-on-change enabled: a successful write changes the file, and the configuration provider remains responsible for observing and publishing that change.

RuntimeWorkingCopy

Gets the detached in-memory working branch intended for runtime-only use.

Declaration
public T RuntimeWorkingCopy { get; }
Property Value
Type Description
T
Remarks

The runtime working copy starts as a deep copy of InitialSnapshot. Mutating it does not modify Current and never writes the backing JSON file. Likewise, persisted changes and file reloads do not automatically overwrite this branch.

Use MutateRuntimeWorkingCopy(Action<T>, bool) for controlled changes, RestoreRuntimeWorkingCopyFromCurrent(bool) to discard runtime-only changes and resynchronize from the current file-backed state, or RestoreRuntimeWorkingCopyFromInitialSnapshot(bool) to return the runtime branch to the store's original startup state.

Treat the returned instance as read-only outside the store mutation methods so that RuntimeWorkingCopyChanged remains a reliable notification boundary.
