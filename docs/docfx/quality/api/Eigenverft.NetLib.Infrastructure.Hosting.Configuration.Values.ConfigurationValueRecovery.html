Class ConfigurationValueRecovery

Provides an explicit local recovery view over clear-text runtime values that were selected by NetLib JSON value protection.

Remarks

Recovery does not decode backing files, bypass a protection boundary, or introduce a second cryptographic path. It reads values that a NetLib switchable JSON provider has already decoded and published into its active runtime configuration snapshot, then limits the result to keys selected by that provider's registered JsonConfigurationValueProtection policy.

RecoverProtectedValues(IConfiguration)

Returns the currently published clear-text values for keys selected by registered NetLib JSON value-protection rules.

Declaration
[Experimental("EVFRECOVERY001")]
public static IReadOnlyDictionary<string, string?> RecoverProtectedValues(IConfiguration configuration)
Parameters
Type Name Description
IConfiguration configuration

The active configuration root or ConfigurationManager whose provider chain contains NetLib switchable JSON sources configured with JsonConfigurationValueProtection.
Returns
Type Description
IReadOnlyDictionary<string, string>

A read-only dictionary keyed by full colon-separated configuration path. Only values from NetLib switchable JSON providers with registered value protection are included. When more than one such provider contains the same key, later provider precedence wins, matching normal IConfiguration resolution.
Remarks

This helper is intentionally intended for short-lived recovery or debugging, for example when the clear text is no longer known but the application still has the protection context needed to load it. A copied configuration can be recovered on another machine when its codec does not depend on host-specific state and all other required inputs are reproduced there. Machine-bound protection, missing passwords, missing key material, or a different codec composition can leave the persisted envelope undecoded; in that case this method fails explicitly instead of returning ciphertext. Run the same configuration bootstrap and recovery call on the original application server when that host owns required protection context. The returned values may contain secrets. Do not log, persist, transmit, or otherwise retain the returned clear text unless that is explicitly intended. The experimental diagnostic is deliberately strong so temporary recovery calls remain visible and are removed when the recovery session is finished.

Exceptions
Type Condition
ArgumentNullException

configuration is null.
ArgumentException

configuration is not an IConfigurationRoot and therefore does not expose its provider chain for recovery inspection.
InvalidOperationException

At least one value selected by a registered protection rule still contains a recognized persisted protection envelope, which means it was not decoded in the current runtime context. The exception identifies the affected key and configured codec name and advises using the original application server when copied configuration depends on host-specific state. Non-host-bound values can be recovered elsewhere when the same password, key material, and codec composition are available.
